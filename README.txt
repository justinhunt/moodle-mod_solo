Poodll Solo Module for Moodle
=============

Poodll Solo is an automatically graded open speaking (or writing) assignment for Moodle.
Students record themselves speaking about a topic (or type a response), and Poodll Solo evaluates
the submission automatically using speech recognition and AI, giving grammar corrections and
other feedback.

Poodll Solo requires a Cloud Poodll API username and secret from https://poodll.com
See here: https://support.poodll.com/support/solutions/articles/19000083076-cloud-poodll-api-secret

See README.md in this folder for the full documentation: features, installation, site settings,
the activity steps, the auto-grading formula and more.
